# Hiring Playbook 📘

A practical, end-to-end playbook for running structured, fair, and fast hiring, from the first intake meeting to the offer call. Built from years of in-house recruiting and designed so any recruiting team can adopt it.



## The principles behind it
1. **Define "great" before you start.** Most stalled searches trace back to an unclear bar.
2. **Assess the same things, the same way, for every candidate.** It's fairer and gives better results.
3. **Evidence over impressions.** Every rating needs a specific example.
4. **Speed is respect.** Clear SLAs keep searches moving and candidates engaged.
5. **Every candidate deserves a clear answer.** How you say no shapes your reputation.

## How to use it
- **Starting a new search?** Begin with step 1, and send the hiring manager a one-page summary afterward.
- **Building a new interview process?** Use steps 2 and 3 together.
- **Debriefs running long or going in circles?** Start with step 4.
- **Want to improve candidate experience?** Step 5 has templates you can use today.
