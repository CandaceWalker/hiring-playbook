# 3. Scorecard

Scorecards turn impressions into evidence. Every interviewer rates only the competencies they were assigned, using the same scale and examples from the interview.

## Rating scale

| Score | Meaning |
|---|---|
| **4: Strong** | Clearly exceeds the bar, with specific evidence |
| **3: Meets** | Meets the bar, with specific evidence |
| **2: Partial** | Some evidence, but not at the bar |
| **1: Not seen** | Assessed, but no evidence of this competency |
| **N/A** | Not assessed in this interview |

A 4-point scale has no middle option, which nudges interviewers to make a call.

## Scorecard template

```
Candidate: [ID or initials]
Role:
Interviewer:
Interview focus:
Date:

Overall recommendation: Strong yes / Yes / No / Strong no

| Competency | Score (1–4 or N/A) | Evidence (what they said or did) |
|---|---|---|
| [Must-have 1] |  |  |
| [Must-have 2] |  |  |
| [Competency 3] |  |  |

What I didn't get to assess:

Questions for the debrief:
```

## Writing good evidence

| Instead of… | Write… |
|---|---|
| "Strong communicator" | "Explained why they chose a queue over direct API calls, and the trade-off in latency" |
| "Not senior enough" | "Described tasks they completed, but not decisions they owned or influenced" |
| "Great culture fit" | "Gave a specific example of resolving a disagreement with a teammate" |
| "Seemed nervous" | *Leave it out.* Focus on what they did or said about the work. |

## Rules
- Submit your scorecard **before** the debrief and before talking to other interviewers, so your view isn't influenced.
- Rate only what you were assigned.
- Every score needs evidence.
- Leave out anything unrelated to the job.
